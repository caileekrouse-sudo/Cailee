# Cailee — Formula Card Assistant

Describe a client sitting in your chair, and get back a full Redken/Goldwell formula card.

## Get it live (no coding required)

[![Deploy to Render](https://render.com/images/deploy-to-render-button.svg)](https://render.com/deploy?repo=https://github.com/caileekrouse-sudo/Cailee)

1. Click the button above. It'll ask you to sign in (email or Google is fine) and connect this GitHub repo — everything is pre-configured.
2. It will ask you to fill in one value called `ANTHROPIC_API_KEY`. Get that value here:
   - Go to **console.anthropic.com** and sign in (or create a free account).
   - Click **API Keys** in the left sidebar.
   - Click **Create Key**, give it any name, and copy the long string it shows you.
   - Paste that string into the `ANTHROPIC_API_KEY` field on the Render page.
3. Click **Deploy**. After a minute or two, Render gives you a web address (like `https://cailee-formula-assistant.onrender.com`) — that's your app. Bookmark it.

That's it — no terminal, no installing anything.

## Using it

Paste a description of the client into the box, pick a line if you have a preference, and click **Generate Formula Card**. You can copy the result or print it.
